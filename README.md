KrazyCare Drug Store

WEDE5020 Web Development (Introduction) — 2026 POE

KrazyCare Drug Store is a fictional luxury pharmacy website developed for the WEDE5020 Web Development (Introduction) Portfolio of Evidence (POE). The website uses the tagline “Luxury Healthcare, Redefined.” It presents pharmacy products, healthcare services, company information, healthcare updates, enquiry options and contact information.

Main features

Responsive design and navigation

The website uses a shared external CSS stylesheet, responsive layouts and navigation links to help users move between pages. CSS media queries support different screen sizes.

Products and services search

The Products page includes JavaScript search functionality that filters displayed product and service items according to the user's search term and provides feedback when no matches are found.

Interactive gallery lightbox

The Gallery page allows users to enlarge an image by clicking it. The enlarged image can be closed using the close button, by clicking the surrounding overlay or by pressing Escape.

FAQ accordion

The About page includes an interactive FAQ accordion. Users can click a question to reveal or hide its answer.

Interactive map

The Contact page uses the Leaflet JavaScript mapping library and OpenStreetMap tiles to display a map with a marker for the fictional pharmacy location in Johannesburg, South Africa. The location is illustrative and does not represent a verified business address.

Enquiry form

The Enquiry page allows users to select an enquiry category, enter their details and receive a response based on the selected category. The response is generated by client-side JavaScript; it does not confirm real stock availability, prices or bookings.

Contact form

The Contact page provides a form for general messages. The form should validate the user's details and prepare a message addressed to the intended recipient. Refer to the current implementation and testing results when documenting its submission behaviour.

SEO and accessibility

The website uses page-specific titles and meta descriptions where implemented, semantic heading structure, descriptive image alternative text and internal navigation links. Responsive styling supports mobile usability.

The repository includes sitemap.xml to list the website's pages for search-engine discovery. A robots.txt file should also be included at the repository root and its sitemap location verified before final submission.

Image file names and alternative text should remain descriptive, and all local resource paths must match the actual file and folder names.
